# StockFlow – Inventory Management System

StockFlow is a web-based inventory management system built using HTML, CSS, and JavaScript. It helps users manage inventory items, assign stock to employees, track returns, and maintain a history of inventory movements.

## 🚀 Live Demo

**[Click here to open StockFlow]([https://stockflow-prakhargoyal-0001.netlify.app/login.html])**

## ✨ Features

- **Inventory Management:** Add, view, update, and delete inventory items.
- **Stock Tracking:** View available quantities and outstanding assigned quantities.
- **Employee Assignments:** Assign specific quantities of inventory to employees.
- **Returns Management:** Record partial or complete returns for individual employee assignments.
- **Stock Status:** Track In Stock, Low Stock, Out of Stock, Damaged, and Under Maintenance items.
- **Restocking:** Update inventory quantities when new stock arrives.
- **Movement History:** Track inventory additions, assignments, returns, restocking, status changes, and deletions.
- **Dashboard:** View inventory summaries and key stock statistics.
- **Search and Filters:** Find inventory items and filter movement records.

## 💾 Data Storage

StockFlow currently uses browser Local Storage. Inventory data is stored in the browser on the device where the application is used. It is not automatically synchronized between different users or devices.
